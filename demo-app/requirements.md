# ターミナル版ToDoアプリの要件

## 目的・対象
自分の日々の作業のやり忘れを防ぐ。個人がローカルのターミナルで使用する新規デモアプリ。
聞き取りと「提案した内容で大丈夫」との指示に基づき確定した。

## 機能・受け入れ条件

| ID | 要件 | 受け入れ条件 | 検証 |
| --- | --- | --- | --- |
| REQ-001 | 追加 | node todo.js add "買い物" で一意な正の整数IDと未完了状態を持つタスクを追加する | 自動 |
| REQ-002 | 一覧 | node todo.js list で追加順にID・名前・未完了 [ ]／完了 [x] を表示する。0件ならその旨を表示する | 自動 |
| REQ-003 | 完了 | node todo.js done 1 で対象を完了にする。完了済みへの再実行でも完了を維持する | 自動 |
| REQ-004 | 永続化 | アプリ配置先のdata/todos.jsonに保存し、別プロセスからも名前・ID・状態を復元する | 自動 |
| REQ-005 | 入力エラー | 空・空白のみの名前、存在しない／不正なID、不明コマンド、不正な引数は日本語エラーを表示し非ゼロで終了する。保存済みデータを変更しない | 自動 |
| REQ-006 | Git除外 | data/をGit管理対象外にする | Git確認 |

## 非機能要件・制約
- Node.js標準機能のみ。外部パッケージ・外部サービス・ネットワーク通信は使わない。
- 個人が順次コマンドを実行するデモ。同時実行・大量データの性能保証は対象外。
- GUI、ログイン、通知、削除、期限、バックアップ機能は対象外。
- 対応確認は現在のWindows／Node.js環境。他環境は未検証。
- 公開先・運用監視・移行は該当なし。追加の予算・期限指定なし。

## 未決事項
実装を妨げる未決事項なし。実際のやり忘れ防止への効果は継続利用で評価する。

## 更新ルール
実装中は変更しない。要件変更は明示的な指示を受けてから行う。
