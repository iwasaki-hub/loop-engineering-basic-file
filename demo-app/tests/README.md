# 自動テスト

## 実行
demo-app内で `node --test` を実行する。標準node:test／assert／child_processを使用。
Node.js v26.13.0、Windowsで確認。外部依存なし。
tests/todo.test.jsが一時ディレクトリへCLIをコピーし、コマンドごとに新しいプロセスで実行する。
利用者用data/には触れず、作成した一時ディレクトリのみテスト終了時に削除する。

## 要件との対応

| 要件ID | テスト名の目印 | 確認内容 |
| --- | --- | --- |
| REQ-001,004 | 日本語の名前と連番 | 名前・連番・未完了状態の保存と別プロセスでの復元 |
| REQ-002 | 初回は0件 | 初回表示とファイル非作成 |
| REQ-002,003,004 | 完了状態の復元 | 全件の追加順表示、完了の保存、再操作・一覧で保存内容不変 |
| REQ-005 | 入力エラー | 14種類の不正入力、日本語エラー、終了コード1、保存内容不変 |
| REQ-006 | Gitによる確認 | git check-ignoreでdata/todos.jsonを確認 |
| 設計上の保護 | 不正な保存データ | JSON破損・不正形式をエラーにし、上書きしない |

## 方針と手動確認
テスト駆動の手順、期待値の保護、修正回数の上限はAGENTS.mdに従う。
実行ごとの結果はtasks.mdに記録する。
文字の読みやすさ・使い勝手・実際のやり忘れ防止効果は、利用者による確認を残す。
他OS・同時書き込み・大量データ・ディスク障害は検証していない。
