# 設計

## 構成
- todo.js：CommonJSのCLI。引数検証、データ読み込み、操作、保存、表示を担当する。
- Node.js標準のfs、pathのみで実装し、依存パッケージやビルドを不要とする。
- tests/todo.test.js：node:testとassertを使い、CLIを別プロセスで実行する。

## データ
data/todos.jsonへ { "id": 1, "title": "買い物", "completed": false } の配列を保存。
IDは最大ID+1、一覧は保存順。名前は前後の空白を除去する。
保存先は__dirname基準で起動場所に依存しない。ファイルがなければ空の配列。
最初の追加で保存ディレクトリを作成する。

## エラーと保存
引数の数、空の名前、正の整数ID、対象の存在を検証。
読み書き失敗・JSON破損・不正な保存形式は日本語のstderrと終了コード1で報告。
破損を空データとして上書きしない。一時ファイルへ保存後に置換する。
一覧と完了の再操作は保存ファイルを書き換えない。同時書き込みは対象外。

## 検証・運用
テスト専用の一時ディレクトリへCLIをコピーし、実際の保存とプロセス間の復元を検証する。
ユーザー用data/には触れず、終了時はテストで作成した一時ディレクトリのみ削除。
対応表はtests/README.md、実行結果はtasks.mdへ記録。
ローカル専用。暗号化・バックアップ・排他制御は対象外。
